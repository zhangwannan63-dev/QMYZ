# 兼容说明

实现依据：原仓库shibig666/QMYZ的master，以及用户仓库截至711dcc0的Python改进版。

完整迁移的主要功能：CLI参数、交互选课、课程列表、本地CSV答案查询、AES解密、目标正确率控制、按实际提交数运行、AI对战、结算积分、对战未知题库追加、多账号Actions。

有意调整：

- 不再默认无限运行。数量必须大于0，避免无限请求。
- 遇到平台验证题直接停止，由用户在官方应用处理，不自动绕过。
- 平台必须明确返回“回答正确！”、“回答错误”或“回答不正确”才计数；其他业务消息停止，不能把HTTP200当作提交成功。
- 原Python对战只保存前5次未知题，本实现对最后一次提交返回的正确答案也保存。
- 原题库路径需改源码，本实现均通过参数配置。
- 保留原CSV每行10列，不擅自归一化题干；多选答案保留如ABCD。
- 原项目随机暂停保持默认3–6秒，提供参数用于本地测试/请求节奏配置，无规避检测功能。
- 不保留工具函数中已注释的full2half（源项目也未启用）。
- 未迁移Python的异常无限重启、打印Cookie、verify=False等行为。
- 原README与GPLv3许可中的作者归属被保留；依赖库许可证分别适用。

验证级别：核心单测和本地模拟服务端端到端测试。真实平台的登录、课程HTML、AES密钥、API字段及对战终止机制均可能变化，尚未进行真实C++提交验证。网络异常时不自动重发提交，可能出现平台已接受但本地无法确认的情况；此时需要人工核对，程序返回失败而不虚报完成。
